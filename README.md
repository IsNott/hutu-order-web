# hutu-order-web

糊涂点餐小程序端

父仓库：https://github.com/isnott/hutu-order

## 介绍

去年新建了Hutu点餐这个项目，原打算使用同一个仓库进行管理，并使用Vue2+UniAPP进行开发，搭起架子后由于各种原因，没有时间开发。
直到最近才对此项目进行了重构，从零开始，重新构建并从原先的仓库中分离出来。

## 重构进度

目前使用mock数据，框架使用Vue3+UniAPP。
除开没有真实数据以外，还欠缺支付模块【暂不会添加】、我的收藏、预定点单到店时间组件等。
大致架子已完成，等待管理后台开发完成后继续。
